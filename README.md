## 주요 기능
* 프로필 CRUD + 회원가입 및 탈퇴
* 게실물 CRUD
* 친구 기능 (팔로워)
* 댓글 CRUD
* 그룹 CRUD
* 검색 기능
* 좋아요 기능 (게시물, 댓글)
* 프로필 공개/비공개 기능

## 트러블 슈팅 기록

### 프로그래밍 시작 전 사전 회의를 통한 트러블 예상
- 프로젝트 진행 중 오류로 인한 트러블 슈팅 없음

### 진행 중 어려웠던 부분
- 기존 진도 차이로 인해 작업량의 차이 발생
- 앞서가는 인원이 뒤처지는 인원을 1:1 케어

###다함께 논의했던 부분
- 기술 구현에 있어 기준을 정할 때 (표기법, 선언 기준 등)
