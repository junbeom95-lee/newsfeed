## 프로젝트 소개
* SNS 뉴스피드 관련기능을 구현했습니다.
* 관심사별로 게시글을 작성할 수 있습니다.
* 게시글과 댓글에 좋아요를 할 수 있습니다.

## 주요 기능
* 프로필 CRUD + 회원가입 및 탈퇴
* 게실물 CRUD
* 친구 기능 (팔로워)
* 댓글 CRUD
* 그룹 CRUD
* 검색 기능
* 좋아요 기능 (게시물, 댓글)
* 프로필 공개/비공개 기능
